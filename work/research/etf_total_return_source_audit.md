# ETF total-return source audit: NIFTYBEES and GOLDBEES (2014–2026)

## Findings

**NIFTYBEES — verified events.** Nippon’s official corporate-action history records a ₹7/unit dividend with record date 11 March 2014, an ₹8/unit dividend with record date 20 February 2015 (both on the pre-split ₹10 face-value unit basis), and a 1:10 face-value split effective 20 December 2019. The 2021 AMC factsheet independently gives each event’s cum- and ex-dividend NAV, confirms ISIN `INF204KB14I2`, and says the scheme tracks Nifty 50 TRI. ([AMC corporate actions](https://investeasy.nipponindiaim.com/rmfGsamnew/Products/NiftyBeES/CorporateAction.aspx), [AMC factsheet](https://mf.nipponindiaim.com/investorservices/factsheetsdocuments/fundamentals-july-2021/Innerpage/ETF-Nifty-BeES.html))

**GOLDBEES — verified event, incomplete absence evidence.** Nippon’s official corporate-action page lists a 1:100 split effective 20 December 2019, but no cash distribution rows. The page does not state that its event history is a complete, certified no-distribution record, so “no distributions” remains unverified. Its product note describes the objective as tracking domestic gold prices and says ETF scheme performance uses IDCW-reinvestment NAVs, assuming any IDCW is reinvested. ([AMC corporate actions](https://investeasy.nipponindiaim.com/rmfGsamnew/Products/GoldBeES/CorporateAction.aspx), [AMC product note, Sep 2025](https://mf.nipponindiaim.com/FundsAndPerformance/ProductNotes/NipponIndia-ETF-Gold-BeES-Sep-2025.pdf))

## Reproducible official data routes

1. **Benchmark total return:** On [NSE Indices’ Historical Data](https://www.niftyindices.com/reports/historical-data), select **Total returns Index Values**, choose the NIFTY 50 index and date range, submit, then download the displayed CSV. The page exposes Date, Total Returns Index and Net Total Return Index fields. NSE explains that TRI includes constituent dividends indexed on ex-dates and reinvested. This is the correct gross benchmark series for NIFTYBEES; it is not the ETF’s traded price or investor P&L. ([NSE TRI methodology](https://www.niftyindices.com/resources/index-concepts/total-return-index), [NIFTYBEES factsheet](https://mf.nipponindiaim.com/investorservices/factsheetsdocuments/fundamentals-july-2021/Innerpage/ETF-Nifty-BeES.html))

   **Project capture (2026-10-27):** The current report interface rejects date ranges longer than 365 days. Six separate NIFTY 50 TR/NTR response windows covering 2014–2019 were saved from the official page, then combined with the existing 2020–2026 capture. The 3,170 unique daily observations from 2014-01-01 through 2026-10-23 match the saved official NIFTY 50 price-index dates exactly. Raw windows, combined source rows and normalized TR/NTR CSVs are listed in `outputs/data_manifest.csv`; reproduce normalization and exact-date checks with `python work/normalize_nifty50_tri.py`. The page-backed request route is undocumented and may change; verify the published file if the route or report fields change.

2. **ETF NAV history:** Use [AMFI NAV History](https://www.amfiindia.com/net-asset-value/nav-download), select the mutual fund and scheme type, enter date ranges, and download text data. AMFI limits each history request to 90 days, so a 2014–2026 pull requires consecutive, non-overlapping windows. The route is reproducible, but a complete 2014–2026 extraction and exact Nippon ETF scheme mapping have **not** been verified in this audit. Raw NAV alone is not an adjusted total-return series when a cash payout occurs: Nippon states NAV falls by the payout and applicable levy, while its performance conventions assume IDCWs are reinvested. Reconstruct unit value by applying verified distributions and the split on their effective dates. ([AMFI download page](https://www.amfiindia.com/net-asset-value/nav-download), [NIFTYBEES event page](https://investeasy.nipponindiaim.com/rmfGsamnew/Products/NiftyBeES/CorporateAction.aspx), [GoldBeES product note](https://mf.nipponindiaim.com/FundsAndPerformance/ProductNotes/NipponIndia-ETF-Gold-BeES-Sep-2025.pdf))

3. **Exchange-price candles and event cross-check:** Upstox V3 daily candles offer OHLC data from January 2000 and permit up to a decade per request. The docs do not promise dividend-adjusted candles; treat them as price candles unless independently checked. Upstox’s corporate-actions endpoint documents dividend/split events with ex-dates, record dates and amounts, but the documentation does not promise complete historical event coverage. An empty event response cannot establish that no action occurred. ([Upstox historical candles](https://upstox.com/developer/api-documentation/v3/get-historical-candle-data/), [Upstox corporate actions](https://upstox.com/developer/api-documentation/get-corporate-actions/))

## Limitations and project implication

- No single official daily, distribution-adjusted market-price series for both ETFs covering all of 2014–2026 was located. AMC performance disclosures use IDCW-reinvestment NAV conventions, while AMFI provides dated NAV records and an official 90-day retrieval limit.
- NIFTYBEES’ known payouts must be included in holder total return when units are held across those events. The current project event audit found zero eligible holdings in all eight candidate paths at both recorded ex-dates; thus those two payouts did not change those tested paths. See [local corporate-action audit](../../outputs/etf_corporate_action_audit.csv). The ₹0.70/₹0.80 per saved post-split price unit conversion is an inference from the 2019 1:10 split, not an AMC quote.
- GOLDBEES’ listed split and the local Upstox candle series look continuous around the split, but continuity is an observation, not a documented adjustment guarantee. Preserve a split-adjustment check in any replay.
- A NAV-based ETF return series measures fund valuation and incorporates fund expenses/tracking effects; an exchange-price strategy replay still needs actual candles plus distributions, split handling, fees, spread and slippage.

**Conclusion:** For strategy benchmarking, use NSE NIFTY 50 TRI. For ETF holder returns, assemble official AMFI NAV windows plus Nippon corporate actions (and verify complete event history); use Upstox prices for executable strategy testing only after split and distribution treatment is explicit. As of this audit, full 2014–2026 distribution-adjusted series coverage for NIFTYBEES and GOLDBEES is **not yet established**.
