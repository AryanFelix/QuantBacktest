# Historical NIFTY options data: coverage, fallback, and backtest limits

**Reviewed:** 2026-10-30. **Scope:** primary-source review for extending the repository's historical NIFTY options sample, especially the missing 2022–2023 expired-contract coverage. This is a data-source note, not a performance claim.

## What Upstox documents

- The Upstox expired-data workflow has three steps: enumerate available expiries, request contracts for a specified expiry, then request candles with the expired contract key. The expiry-list page explicitly says it covers up to six months of historical expiries. The expired-contract and expired-candle endpoints are documented as Upstox Plus-only (`UDAPI1149`). The docs do not promise that every historical expiry/contract is available, and the six-month statement belongs specifically to the expiry-list API. [Get Expiries](https://upstox.com/developer/api-documentation/get-expiries/), [Get Expired Option Contracts](https://upstox.com/developer/api-documentation/get-expired-option-contracts/), [Expired Historical Candle Data](https://upstox.com/developer/api-documentation/get-expired-historical-candle-data/)
- Expired contracts expose the contract identity and specifications needed to avoid reconstructing historic symbols or lots: expiry, instrument key, symbol, CE/PE, strike, lot size, tick size, and weekly flag. Expired candles document 1-, 3-, 5-, 15-, and 30-minute plus daily intervals, returning timestamp, OHLC, volume, and OI. The sample request spans old dates, but the docs state no guaranteed earliest date or completeness level. [Expired Option Contracts](https://upstox.com/developer/api-documentation/get-expired-option-contracts/), [Expired Historical Candles](https://upstox.com/developer/api-documentation/get-expired-historical-candle-data/)
- Candle OHLCV/OI is not historical bid/ask, queue depth, or a guarantee of executable fills. Minute bars can check bar-based signal logic and support explicit slippage stress tests; they cannot prove a fill at an intrabar high/low or resolve queue position. A daily-bar replay cannot support intraday stops or exact intraday option-entry prices.

## Repository preflight observations

The authenticated expired-contract probe returned successful API responses with no contracts for NIFTY expiries 2022-01-27, 2022-06-30, 2022-12-29, 2023-06-29, and 2023-12-28; the earlier 2022-09-29 sample was also empty. In contrast, 2024-10-31 returned 230 contracts and 2026-09-29 returned 288. This is a small date-stratified sample, not proof that every earlier expiry is unavailable, but it is enough to fail the current 2022–2023 contract-level validation gate. The reproducible sample is in [`nifty_expired_option_contract_history_probe.csv`](../../outputs/nifty_expired_option_contract_history_probe.csv); query code is [`probe_nifty_expired_option_coverage.py`](../probe_nifty_expired_option_coverage.py).

## Official NSE alternatives

- NSE's historical contract-wise price-volume page exposes filters for instrument, symbol, year, expiry, option type, strike, and date range, with CSV download. Its output includes trade date, contract, strike/type, open/high/low/close, settlement, OI, contract count, and turnover. This is a practical EOD source to check daily spread marks, traded volume, and whether the chosen contract traded. The page is not an intraday quote tape. [NSE Historical Contract-wise Price Volume Data](https://www.nseindia.com/report-detail/fo_eq_security)
- NSE's official F&O data description documents a daily bhavcopy/master/snapshot/trades organization beginning at 2003-01. The described bhavcopy includes date, underlying, instrument, expiry, option type, strike, OHLC, last-traded price, OI, traded quantity/value, and trade count. Contract masters include lot and token fields. NSE's current reports page says the older common F&O bhavcopy was discontinued on 2024-07-08 and points users to the UDiFF common bhavcopy; preserve the file-format regime boundary when building a continuous panel. [NSE F&O Historical Data Description](https://nsearchives.nseindia.com/content/press/Data_Details_F_n_O.pdf), [NSE All Reports: Derivatives](https://www.nseindia.com/all-reports-derivatives)
- NSE's description distinguishes EOD bhavcopy from the deeper historical trade and order-book data: it documents individual trades and order-book snapshots, and explains snapshots can show bid/ask depth and help estimate market impact, while being discrete snapshots rather than continuous depth. That distinction matters for execution claims. NSE Data's published usage policy says subscribers must communicate the use case, execute a relevant agreement, and commercial market data is priced under NSE Data terms. Research access also has documentation and pricing restrictions. Confirm permitted access/use with NSE Data before bulk acquisition, redistribution, or deployment. [NSE F&O Historical Data Description](https://nsearchives.nseindia.com/content/press/Data_Details_F_n_O.pdf), [NSE Data Usage and Data Sharing Policy](https://nsearchives.nseindia.com/web/sites/default/files/inline-files/NSE_Data_Sharing%26Usage_Policy.pdf)

## What the sources can support

| Data | Reasonable use | Not established by that data |
|---|---|---|
| NSE contract-wise EOD CSV / bhavcopy | Daily contract universe, historic lot/expiry metadata where the master is available, close-to-close option-spread screening, volume/OI filters, end-of-day mark-to-market | Intraday entries/exits, stop order path, bid/ask crossing cost, fill probability, queue position |
| Upstox expired OHLCV/OI candles | Bar-based option backtests on dates/contracts whose candles were actually returned and coverage reconciled | Complete 2022–2023 coverage, quote spread, actual market-order fill or passive-order queue execution |
| Licensed NSE trades / order-book history | More precise trade-time and discrete liquidity analysis according to the product supplied | Continuous queue execution unless the supplied depth/order events and timestamps are sufficient and correctly reconstructed |

## Recommended repository gate

First test the NSE contract-wise EOD CSV route for the exact 2022–2023 monthly expiries and selected strikes. Join using trade date + underlying + expiry + option type + strike; reconcile contract lot-size history independently and report missing contract-days before calculating P&L. Use this only for a daily-bar strategy with a fill convention fixed in advance. Keep intraday derivative tests blocked until every signal day can be joined to the chosen contract's intraday bars, timestamps/session boundaries are checked, and a defensible fill/slippage model is specified. Never replace a missing expired contract or price with a neighboring expiry/strike or a synthetic option price.

The exchange pages and data-sharing rules are mutable; re-check the live source and agreement terms when acquisition begins. This review did not download NSE archives, measure their current date coverage, or establish commercial/republication rights for this personal project.
