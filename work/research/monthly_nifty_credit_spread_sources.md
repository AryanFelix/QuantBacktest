# NIFTY monthly option replay: source and data notes

**Reviewed:** 2026-10-27. **Scope:** first-party API, contract and fee facts for a defined-risk NIFTY monthly vertical-spread replay using the cached 2024-10–2026-09 option sample. This is a data/method note, not a claim that any strategy is profitable.

## Upstox expired-instrument data

- The expired-option workflow is: list available expiries for an underlying, retrieve expired option contracts for one `expiry_date`, then request candles using that contract's expired `instrument_key`. Upstox places the expired-instrument APIs under its Plus plan; `UDAPI1149` specifically means the plan does not permit the request. An Analytics token alone does not establish Plus eligibility. [Expired Instruments API launch](https://upstox.com/developer/api-documentation/announcements/expired-instruments-api/), [expired option contracts](https://upstox.com/developer/api-documentation/get-expired-option-contracts/)
- The expired-candle route is `/v2/expired-instruments/historical-candle/{expired_instrument_key}/{interval}/{to_date}/{from_date}`. The documented intervals are `1minute`, `3minute`, `5minute`, `15minute`, `30minute`, and `day`; both dates are required and inclusive. Returned rows contain timestamp, OHLC, volume, and open interest. The expired-candle page gives no explicit maximum lookback or date-span limit; do not assume limits documented for the separate regular or V3 historical-candle APIs apply here. [Expired historical candles](https://upstox.com/developer/api-documentation/get-expired-historical-candle-data/)
- Upstox says expired APIs follow standard authentication and rate limits. Its current standard-API limits are per API and per user: 50 requests/second, 500/minute, 2,000/30 minutes. Contract retrieval is per expiry and candles are per contract key, so cache successful responses and pace bulk backfills. [Expired API launch](https://upstox.com/developer/api-documentation/announcements/expired-instruments-api/), [rate limits](https://upstox.com/developer/api-documentation/rate-limiting/)
- Candles are trade-bar OHLCV/OI, not historical bid/ask quotes, queue depth, or a guaranteed executable fill. Minute bars are available by specification, but their historical coverage for every selected leg/date must be checked empirically. A daily-bar spread replay cannot model intraday stops or spread-level fill prices; use explicit adverse-slippage scenarios and state the fill convention.

## Cached sample and contract regime changes

- The repository has 24 cached NIFTY monthly option-contract snapshots, expiry dates 2024-10-31 through 2026-09-29. The snapshot contract schema includes expiry, instrument key, trading symbol, lot size, CE/PE type, strike, and a `weekly` flag; for the replay, use the historical contract metadata and exact expiry date rather than reconstructing old symbols or assuming today's lot size. Upstox documents those fields in its [expired option contract response](https://upstox.com/developer/api-documentation/get-expired-option-contracts/). The cached responses live under [`work/data/expired`](../data/expired/).
- The cached option lots are 25 for expiries through 2025-01-30, 75 for 2025-02-27 through 2025-12-30, and 65 for 2026-01-27 through 2026-09-29. This agrees with NSE's notices: 25→75 for new contracts introduced from 2024-11-20, with monthly 2025-01-30 the last old-lot expiry and 2025-02-27 the first revised-lot expiry; then 75→65, with monthly 2025-12-30 the last old-lot expiry and 2026-01-27 the first revised-lot expiry. [NSE circular 128/2024](https://nsearchives.nseindia.com/content/circulars/FAOP64625.pdf), [NSE circular 176/2025](https://nsearchives.nseindia.com/content/circulars/FAOP70616.pdf)
- The monthly expiry convention in the cached era changes during the sample: Thursday expiries through 2025-08, then Tuesday expiries from 2025-09. NSE re-aligned existing NIFTY long-dated expiries from the September 2025 expiry onward to Tuesday (the quarterly September expiry moved from 2025-09-25 to 2025-09-30); the next new monthly expiry was 2025-10-28. NSE's current specification says Tuesday, or the previous trading day if Tuesday is a holiday. Use the actual expiry in each contract snapshot / expiry API response, including holiday shifts. [NSE circular 68747](https://nsearchives.nseindia.com/content/circulars/FAOP68747.pdf), [current contract specifications](https://www.nseindia.com/static/products-services/equity-derivatives-contract-specifications)
- Upstox's expired-option response documents `weekly` as a boolean, but does not document a monthly-vs-quarterly cycle field. NSE lists separate quarterly NIFTY expiries; those can coincide with a calendar month's expiry. Define the tested universe by the chosen monthly calendar-expiry dates, and do not interpret `weekly=false` alone as proof that a contract is a monthly-series contract. The prior code filters on `weekly` and expiry date, which is adequate for the monthly calendar-date strategy definition but is not a full cycle classification. [Upstox contract fields](https://upstox.com/developer/api-documentation/get-expired-option-contracts/), [NSE specifications](https://www.nseindia.com/static/products-services/equity-derivatives-contract-specifications)
- Existing replay evidence shows sample-specific holes: the 2024-12-26 selected expired contracts returned no daily candles, and the 2025-04-30 cached chain had no monthly option contracts after the `weekly` filter. The prior debit-spread replay therefore has 22 eligible expiry trades out of 24 snapshots. Treat this as an observed coverage limitation, not a general API guarantee; do not silently substitute a nearby expiry or fabricate missing prices. See [`monthly_nifty_spread_reproducible/summary.json`](../backtests/monthly_nifty_spread_reproducible/summary.json) and selection/failure handling in [`upstox_quant.py`](../upstox_quant.py).

## Fees to apply to a credit spread

For each filled option leg and side, the current Upstox schedule shows flat ₹20 brokerage per executed options order, STT on option sales by premium value, ₹0.003% stamp duty on option buys, ₹10/crore SEBI charge, and 18% GST on brokerage + transaction + IPFT charges; options have no DP charge. If a position is held to expiry and exercised, model the separate exercise-STT charge on intrinsic value: 0.125% through 2026-03-31 and 0.15% from 2026-04-01. [Upstox charges](https://upstox.com/brokerage-charges/), [NSE STT schedule](https://www.nseindia.com/static/products-services/equity-derivatives-securities-transaction-tax)

For this cached period, date-aware sell-side option STT is 0.10% through 2026-03-31 and 0.15% from 2026-04-01. The NSE premium transaction/IPFT schedule also changed on 2026-03-01: before then, 0.03503% transaction charge plus IPFT ₹0.50/lakh on options premium (₹3,553/crore combined); from then, NSE's exact circular decomposition is ₹3,552/crore transaction charge plus ₹0.01/crore IPFT. Upstox displays 0.03553% as the current NSE option transaction rate. [Upstox charge schedule](https://upstox.com/brokerage-charges/), [NSE circular 1/2026](https://nsearchives.nseindia.com/content/circulars/FA73061.pdf)

The shared fee helper in [`upstox_quant.py`](../upstox_quant.py) now receives each fill date and applies the published 0.10% options STT through 2026-03-31 and 0.15% from 2026-04-01. It applies the earlier 0.03503% transaction charge plus ₹0.50/lakh IPFT through 2026-02-28, then the NSE circular's 0.03552% plus ₹0.01/crore from 2026-03-01. The helper rejects dated option simulations before 2024-10-01, the start of this audited fee ledger. Charge STT on every option sell fill, including a long-leg close; charge buy-side stamp duty on every option buy fill. Add brokerage per executed leg order, not per two-leg spread ticket, unless the broker's actual fill/charge records show otherwise. Model slippage separately from statutory charges.
